# OWL选手之路 · 路线图与 TODO

> 当前维护基线：**2.0 Alpha 1 · Batch2**
>
> 本文档用于长期维护项目路线、优先级、完成状态与待验证事项。  
> 原则：**“代码已改”不等于“功能已验收”**。所有涉及赛制、存档、跨年、移动端、奖项、世界杯、交易、英雄选择的改动，至少需要进入 QA 文档对应回归项。

---

## 0. 当前版本定位

2.0 Alpha 1 已经不再只是“职业生涯数值模拟器”，当前主线正在转向：

- **活的职业世界**：战队 DNA、教练、管理策略、队友关系、位置竞争、建队周期。
- **更真实的比赛生态**：地图池、版本轮换、英雄选择、Hero Ban、OWCS Loser's Pick、主客场与队伍体系。
- **完整职业生命周期**：新秀 → 轮换/首发 → 转会/续约 → 国家队 → 巅峰/下滑 → 退役 → 生涯档案。
- **历史模式 + 梦幻演化模式**并存。
- 2019～2023 以 OWL 史实结构为基础，2024+ 进入 OWCS / 动态世界。
- 后续最终目标仍是：**2016 起真实模式**，但必须等当前 2.0 底座稳定。

# 1. 当前版本收口优先级

## P0 · 必须在下一次公开试玩前继续处理

### 1.1 长档稳定性
- [ ] 跑至少 **3 类 6～10 年完整生涯档**：
  - 明星核心
  - 普通稳定首发
  - 边缘轮换 / 多次转会
- [ ] 至少再跑 1 个 **15 年极限长档**。
- [ ] 观察是否出现：
  - 教练更替过快 / 完全不换
  - 战队 DNA 过度固化
  - 队友关系长期锁死
  - 俱乐部强弱阶层永久不变
  - AI 老将不退役
  - AI 新秀数量不足
  - AI 转生过量
  - 合同市场无人可签 / 满地巨星
  - 国家队阵容年年高度雷同
  - 赛季事件重复严重

### 1.2 Batch1 + Batch2 新改动完整回归
> 当前为“已实现，待完整真人回归”，不能视为彻底验收。

- [ ] 常规赛赛程圆点在短赛程 / 长赛程 / 手机端不再挤成一团。
- [ ] 季后赛快速模拟按轮展示结果，不再瞬间跳完整个季后赛。
- [ ] 季后赛最终轮有冠军 / 亚军结算弹窗。
- [ ] 世界杯选项不再泄露后台数值。
- [ ] 世界杯冠军有冠军撒花 / 庆祝动效。
- [ ] 2024+ “查看常规赛选项”位置稳定，不再掉到底部。
- [ ] 英雄选择不再长期锁死绝活英雄。
- [ ] 2019～2023 版本强度真正影响英雄选择。
- [ ] 2025+ Hero Ban / Plan B 使用同一套英雄适配逻辑。
- [ ] Dennis Hawelka 奖不再成为玩家点击就送。
- [ ] 队伍信息显示玩家当前年龄。
- [ ] 全明星正常首发不再错误显示“原定首发”。
- [ ] 国家队磨合支持俱乐部队友与历届国家队队友继承。

- [ ] 退役后的“生涯赛季记录”按倒序显示。

### 1.3 模拟完整赛季性能
- [ ] 建立性能基准：
  - 2019 完整赛季
  - 2023 完整赛季
  - 2025 完整赛季
  - 2035 扩军后完整赛季
- [ ] “模拟完整赛季”只能走轻量结果模型。
- [ ] 禁止整季快速模拟偷偷调用：
  - 完整地图 Pick
  - Hero Ban
  - 逐图阵容
  - 完整战术计划
  - 地图级详细比赛循环
- [ ] 连续模拟过程中 UI 分批刷新，避免主线程长时间假死。
- [ ] 记录不同机器上的主观卡顿情况，目标是普通 PC 上无明显“浏览器未响应”。

### 1.4 存档安全
- [ ] 老版本存档迁移到 2.0 Alpha 1 Batch2。
- [ ] 读档后：
  - 队伍正确
  - 年份正确
  - 合同正确
  - 队友关系正确
  - 世界杯状态正确
  - Stage / Major 状态正确
  - 地图池状态正确

- [ ] 所有新字段必须允许旧档缺省初始化。
- [ ] 不允许因新增字段导致旧档直接无法进入比赛。

# 15. 当前明确不应回退的产品决策

以下内容视为已经定稿或高优先级原则，后续修改不得无故回退：

- “模拟常规赛” = 常规赛全部 + Stage 季后赛，**不包含年度 Final**。
- 自动加点只负责“加点”，不自动继续下一流程。
- 休赛期英雄训练长期平衡使用 **7 / 5 / 3 / 2**。
- Career Feed 对阵前显示 `G x`。
- 季后赛手机端默认突出玩家路径，可展开完整赛事。
- Major 是 Stage 阶段赛事，不是年度季后赛。
- 2024+ 世界演化细节不直接给玩家看后台数值。
- 世界杯在俱乐部全年赛事结束后进行。
- 世界杯落选仍能查看赛事结果。
- 国家队磨合允许历史继承。
- 2025+ OWCS 选图遵循 Loser's Pick 逻辑。
- Dennis Hawelka 奖不能成为玩家保送奖。
- 退役赛季记录倒序。
- 合同 / 转会界面必须能查看真实阵容、合同与准备退役状态。
- 正式版手动发布，测试版自动部署。
